### [Metamap](https://github.com/JuanManuelRama/metamap-dds-utnfrba-2025)
Open-source collaborative mapping platform originally built for an NGO, supporting anonymous and registered contributors who submit geotagged reports (text, image, video). Features decentralized data aggregation, configurable consensus algorithms to filter misinformation, full-text search, and async background jobs for caching and analytics. Rendered server-side with REST integration for inter-instance federation.

`Java` `Javalin` `Hibernate` `MySQL`

### [OS Simulator](https://github.com/JuanManuelRama/SO-1c-2024)
Distributed operating system simulator built across four communicating modules — Kernel, CPU, Memory, and I/O. Implements a full process lifecycle with PCB tracking, FIFO/Round Robin scheduling, MMU-based address translation with a TLB, demand paging, and a custom file system with contiguous block allocation and compaction.

`C` `Sockets` `Makefile` `Distributed Systems`
